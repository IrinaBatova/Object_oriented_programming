# Проект "Object_oriented_programming"

## Описание:

Проект "Object_oriented_programming" - это контрольные работы на Python по разделу 4
"Объектно-ориентированное программирование" в рамках обучения по программе 
"Python-разработчик".

## Установка:

1. Клонируйте репозиторий:
```
git@github.com:IrinaBatova/Object_oriented_programming.git
```

2. Все данные о проекте находятся в файле:
```
pyproject.toml
```

## Использование:

1. Запустите файл main.py
2. Введите запрошенные данные.

## Тестирование:

1. Для тестирования используется библиотека pytest
2. Запуск тестирования: введите команду poetry run pytest --cov в терминале.
3. Code coverage 80%.
